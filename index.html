ui-kit

A framework-free house style: design tokens and components in plain CSS, with HTML examples you can copy from. Built for readable dashboards — almond and carbon neutrals, charcoal-blue accent, WCAG 2.2 AA.

Walk through the kit in three chapters — foundation tokens, core components, then dashboard patterns composed from those pieces.

Chapters

  • Foundation — colour, type, spacing and elevation tokens in ui-kit.css, with live swatches and contrast notes.

  • Components — buttons, forms, tables, tags, banners and layout primitives; each section explains when to use the pattern and shows every state.

  • Composition — panels, key figures, sortable tables, charts and activity trails built only from kit classes; optional ui-kit.js for table sort and filter.

Get started

Copy ui-kit.css (and optionally ui-kit.js) into your project. Override tokens in your own stylesheet loaded after the kit. Run npm test in this repository for contrast and accessibility checks.
