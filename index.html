Documentation chapters

  • Foundation — palette, type, spacing, elevation and contrast checks with a theme switch.

  • Components — forms, buttons, tables, tags, breadcrumbs, tabs, dialogs and layout primitives.

  • Composition — panels, figures, sortable tables, charts and activity trails; optional ui-kit.js.

  • Content style — voice for headings, buttons, errors and British spelling.

Theme presets in presets/ (default-serif, minimal-square, matt-warm) load after ui-kit.css.

Adopt the kit

  1. Copy tagged ui-kit.css (and optionally ui-kit.js) from the latest release or this repo.
  2. Link the stylesheet after your reset, before your project CSS; optionally add a file from presets/.
  3. Override hooks documented in the README if you need a distinct accent.
  4. Run npm test in this repository when you change tokens or examples.
