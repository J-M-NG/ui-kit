One stylesheet for forms, tables and dashboards

Copy ui-kit.css into a project and link it before your own CSS. No framework, no build step, no web fonts. Includes an optional script for sorting, filtering, tabs and dialogs, plus a matching Streamlit theme.

Presets and project hooks

Projects may override three things in an unlayered stylesheet loaded after ui-kit.css: accent colour, heading face and corner radius. Everything else stays shared.

Using it in a project

Copy ui-kit.css from a pinned commit (or a release once tagged) and load it before your own stylesheet. Run the contrast check whenever you change colours.

<link rel="stylesheet" href="static/ui-kit.css">
<link rel="stylesheet" href="static/project.css">
<script src="static/ui-kit.js" defer></script>

# Verify contrast in both light and dark themes
python3 tests/check_contrast.py --project static/project.css
