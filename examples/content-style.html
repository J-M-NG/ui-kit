Guide

Content style

How to write copy that fits the kit: plain, active sentences; British spelling; accessible patterns without government-service tone.

Voice

  • Prefer you and name the action (“Save changes”, not “Save and continue”).
  • Headings state the topic; buttons state the outcome.
  • Errors say what to fix, with an example when format matters.
  • Status tags always include a word; never rely on colour alone.

Headings

Editorial serif by default; body stays system UI. Use sentence case unless a proper noun needs capitals.

Good

Tasks this week — scannable, specific.

Avoid

Your tasks — vague service phrasing when the screen already shows tasks.

Buttons and links

Use one primary button per view. Link text should describe the destination (“Open composition demo”).

Errors and validation

Fix these fields

  • Enter a board name with at least three characters
