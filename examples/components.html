Chapter 2

Components

Each building block in order: type, actions, forms, feedback, data display and page chrome. Every class styles a real HTML element, so it works without JavaScript and with assistive technology.

Typography

Headings, body copy and links come from the base layer in ui-kit.css. Sizes map to the tokens on the Foundation page; do not set font sizes ad hoc.

Section heading

Use clear, active sentences. Keep line length comfortable — paragraphs are capped with --jm-measure.

Secondary text for metadata, hints and timestamps.

Inline link with underline and visible focus.

Semantic <h1>–<h4>, <p>, <a>; utility .jm-secondary-text for de-emphasised copy.

Buttons

Say what the button does. Use one primary button per screen; warning buttons only for actions that destroy something.

Link styled as a button

.jm-button, --secondary, --warning; works on <button> and <a>.

Text input, textarea and select

Group each control with a label, optional hint and error message. Hints use aria-describedby so screen readers announce them with the field.
