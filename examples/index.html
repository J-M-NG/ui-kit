Chapter 1

Foundation

The tokens everything else is built from. Use the semantic colour tokens (--jm-colour-text), not palette names. The theme follows the operating system unless you set data-theme on <html>.

Swatches update when you change theme. tests/check_contrast.py checks every text pair for 4.5:1 and borders, focus rings and status marks for 3:1.

Surfaces, text and borders

    Accent, links and focus

      Status

      Each status has a colour for icons and borders, a text colour and a tinted background. Always pair the colour with a word or icon.

      Success Body text on the success background. --jm-colour-success-*
      Warning Body text on the warning background. --jm-colour-warning-*
      Error Body text on the error background. --jm-colour-error-*
      Information Body text on the information background. --jm-colour-info-*

      Type scale

      No web fonts. Page and section headings (h1 to h3) use the serif stack in --jm-font-family-heading; body text, labels and component titles use the system sans. Body text is --jm-font-size-md (16px).
